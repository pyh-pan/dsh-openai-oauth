# Safe installation runbook

This is the independent SIWC project at https://github.com/pyh-pan/dsh-openai-oauth, not the older similarly named Codex plugin.

1. Confirm a local Windows/macOS Desktop installation; keep its Host modules native. Loading uses the minimum `>=0.2.0-rc.2`, not a future-version whitelist. Read docs/forward-compatibility.md for unknown metadata, optional capabilities and real contract failures; consult docs/compatibility.md for platform-specific validation evidence.
2. Read README and docs/install.md. Develop in an isolated checkout while Desktop uses an existing link. Use Node 24+, `npm ci`, `npm test`, `npm run check`, `npm run test:package`, then `npm run doctor`; run all four native suites explicitly before deployment. These suites are development/release checks, never production activation dependencies.
3. Inspect existing bundles without printing full config or credentials. If an older private bundle already owns this source, follow docs/migration.md; never activate both owners concurrently.
4. Install through the native plugin manager/CLI: `npm run dsh -- plugin --profile desktop add -w .`. Keep linked installations linked; do not remove then add an archive over a Windows Junction (the installed rc.2/pnpm tuple can delete the linked checkout). Verify actual version, canonical target and selected bundle, not just exit zero. See docs/install.md. Do not manually rewrite profile package/lock/patch files or modify ASAR/framework dependencies.
5. Deploy from an external terminal/independent assistant, never a DSH conversation using the provider being replaced: HMR can dispose it immediately. The idle window must include the deploying conversation. Ask before restarting if tasks are running. Use normal Quit, not forced process termination.
6. Ask the user to complete official authorization and select their account. Never receive/export tokens, read credential contents, or sign in as them.
7. Verify the original model picker contains the independently attributed subscription source and does not replace other providers. Run test:presets, inspect every supported preset and the target Agent's exact retained composition. Read the native agentPreset projection/selection events, never just the creation header or standard default. Coverage/compaction failures must stop SIWC conversation dispatch, not grow history. One provider bundle owns integration; migrate the former local compatibility bundle only through the native manager. Do not automatically change the current model.
8. Real inference/refresh/revocation are not part of an unattended install. Obtain bounded approval; don't use full user conversation history for a test.
9. Report OS/architecture/DSH version, bundle reference, safe checks, restart state and any unverified boundary. Never claim macOS GUI compatibility from a Node CI pass.

Stop the affected operation on unknown content, a proven below-minimum Host, missing/failed necessary contracts, credential requests, unsafe restart or license/permission conflicts. New/unknown version labels and different component version strings alone do not stop activation; inspect actual capabilities and module identity. Never force-push, weaken TLS/SSRF settings or approve unrelated lifecycle scripts to continue.
